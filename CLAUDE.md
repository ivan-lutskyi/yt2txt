# yt2txt — YouTube → транскрипт → файл для аналізу в ШІ

## Мета
Локальний інструмент для Windows: на вхід посилання на YouTube-відео (переважно українською, рідше англійською чи російською), на виході `.md` файл з транскриптом і промптом. Цей файл я вручну кидаю в Claude і отримую вижимку, перевірку фактів, аналітику та висновки.

## Як працює `yt2txt.py`
1. `yt-dlp` (Python API) завантажує тільки аудіо (`bestaudio`) у тимчасову папку.
2. `faster-whisper` розпізнає мовлення локально. Мову визначає автоматично або бере з `--lang`.
3. Сегменти склеюються в абзаци (новий абзац після паузи понад 2 с або кожні ~60 с), до кожного абзацу додається таймкод `[mm:ss]`.
4. Пише `transcripts/<YYYYMMDD>_<назва>.md` у такому порядку: метадані (канал, дата, тривалість, URL, шаблон посилання на момент відео `?t=`, визначена мова, модель), транскрипт у `<transcript>…</transcript>`, промпт для ШІ (`DEFAULT_PROMPT` або `--prompt-file`).
5. Поруч кладе `<те саме ім'я>.jpg` — обкладинку для статті 1280×720. За замовчуванням (`--cover own`) вона власна, без чужих зображень: темний градієнт із точковою сіткою, зелена плашка «АНАЛІЗ ВІДЕО» + «фактчек · аргументи · висновки», назва відео в лапках «…» (кегль підбирається під 4 рядки), праворуч лупа з кнопкою ▶, унизу таймлайн з позначками, канал · дата · тривалість. Малюється у 2× і зменшується для згладжування; напівпрозоре малюємо на RGB через `ImageDraw.Draw(img, "RGBA")`, бо на RGBA Pillow не змішує кольори. `--cover thumb` ставить на превʼю відео зелений бейдж «✓ ПРОАНАЛІЗОВАНО» (текст: `--stamp`), `--cover none` вимикає обкладинку.

Параметри: `--lang uk|en|ru`, `--model large-v3|large-v3-turbo|medium|small`, `--device auto|cuda|cpu`, `--out <папка>`, `--prompt-file <файл>`, `--stamp <текст мітки>`, `--cover own|thumb|none`. Можна передати кілька URL одразу.

## Свідомі рішення (не змінювати без причини)
- **Промпт іде після транскрипту.** На довгих документах моделі краще виконують інструкції, що стоять в кінці.
- **`vad_filter=True`.** Вирізає тишу й музику, щоб Whisper менше галюцинував.
- **`condition_on_previous_text=False`.** Запобігає зациклюванню тексту на довгих відео.
- **ffmpeg не потрібен.** yt-dlp не перекодовує аудіо, faster-whisper декодує його сам через PyAV.
- **GPU з fallback.** `--device auto` пробує CUDA (`float16`), а якщо не вийде, переходить на CPU (`int8`).
- **Промпт обробляє помилки розпізнавання.** Він просить ШІ зважати на спотворені імена й числа і чесно позначати, коли перевірка йде без вебпошуку.
- **Результат аналізу — стаття для telegra.ph.** У редакторі telegra.ph немає таблиць, вкладених списків і є лише два рівні заголовків. Тому фактчек іде списком, а таймкоди стають посиланнями `youtu.be/ID?t=N`. Нотатки для редактора йдуть після рядка «===== НЕ ДЛЯ ПУБЛІКАЦІЇ =====».
- **Обкладинка за замовчуванням власна, а не превʼю автора.** Чуже превʼю як «обличчя» статті — слабка підстава для цитування, воно поширює чужий клікбейт, а обличчя з міткою «ПРОАНАЛІЗОВАНО» легко сприйняти як атаку на людину. Превʼю можна додати всередину статті з підписом про джерело.
- **Бейдж (лише для `--cover thumb`) угорі праворуч.** Унизу превʼю YouTube зазвичай стоять назва й логотип каналу, і їх не варто закривати. Галочку малюємо лініями, бо в шрифті може не бути символу ✓. Шрифт: Segoe UI Bold.

## Середовище — все в папці проєкту
```
.venv\            віртуальне середовище Python
.venv\Scripts\deno.exe   JS-рантайм для yt-dlp (потрібен для YouTube)
models\           кеш моделей Whisper (через HF_HOME)
transcripts\      результати
run.bat           запуск з правильними змінними середовища
```

Налаштування з нуля (PowerShell у папці проєкту):
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U -r requirements.txt
# deno.exe: завантажити deno-x86_64-pc-windows-msvc.zip (саме x86_64, НЕ aarch64)
#           з github.com/denoland/deno/releases і розпакувати в .venv\Scripts\
```
Запуск: `run.bat "https://youtu.be/..."`

## Статус (2026-10-14)
- Повний ланцюжок перевірено на короткому відео (модель `tiny`, GPU): завантаження → розпізнавання → `.md`.
- CUDA працює: RTX 4060 8 ГБ. cuBLAS і cuDNN 9 стоять у `.venv` як pip-пакети `nvidia-*`, `yt2txt.py` сам додає їхні `bin` у PATH.
- `load_model` робить пробне розпізнавання 1 с тиші на GPU, бо ctranslate2 підвантажує cuBLAS/cuDNN лише на першому `encode`. Без цієї перевірки помилка вилізла б уже на реальному відео й перехід на CPU не спрацював би.
- PyAV закріплено на `<19`: faster-whisper 1.2.1 викликає `av.open(metadata_errors=...)`, а в PyAV 19 цього параметра немає. Прибрати обмеження, коли faster-whisper це виправить.
- `large-v3` на реальному відео ще не запускався (модель ~3 ГБ завантажиться в `models\` під час першого запуску).

## Можливі наступні кроки (за бажанням)
- Якщо yt-dlp падає на YouTube: оновити його (`pip install -U yt-dlp`) і перевірити, що Deno є в PATH.
- Пропускати відео, для яких файл уже існує.
- Підтримка плейлистів.
- Пізніше використати це як вхід для Telegram-бота аналізу маніпуляцій: відправляти файл у Claude API автоматично, без ручного кроку.
